## 2. 평가 산식 ★ (평가 탭)

**Brier Skill Score 변형:**

```
Score = max(0, 100000 × (1 − Brier Score / 평균 제구율 Brier Score))

Brier Score          = mean((p_i − y_i)²)
평균 제구율 Brier Score = r × (1 − r),  r = 전체 평가 데이터의 평균 제구 성공률 (비공개)
```

- 즉 **"항상 r을 찍는 기준 모델 대비 얼마나 개선했는가"** × 100,000. 기준 모델과 같으면 0점.
- **Public Score = 전체 테스트 데이터 100%**
- **Private Score = 대회 종료 시점의 Public Score** → **Public/Private 분할이 없다. 셰이크업 없음.**
- 1차 평가: Private Score 100% → 2차: 코드 검증 (상위 약 100명 코드+PPT 필수 제출)

이 조항이 금지하는 것:
- ❌ **test 구간 내 롤링/시퀀스 피처** — 2025년 이전 투구(=test의 다른 행)를 집계해 현재 행 피처로 쓰는 것
- ❌ **test 예측 분포 기반 보정** — test 예측 평균을 보고 base rate 오프셋을 거는 것
- ❌ pseudo-labeling, test-time adaptation 일체

즉 **"등판 내 흐름" 피처는 test 행 자체에 그 정보가 컬럼으로 들어있을 때만 사용 가능**하다.
→ 데이터 명세 공개 시 test.csv에 어떤 이력 컬럼이 포함되는지가 피처 전략의 최대 변수.

