## 1. 이 제출물의 구조 — 다섯 팔의 로짓 결합

최종 예측은 학습된 팔 다섯 개를 로짓 공간에서 가중 평균한 뒤, 순수 사후 변환(행 단위 상수 이동)을 얹은 것이다.

```
z = w_v6·lg(p_v6) + (1−w_v6)·lg(p_Q)          ← 팀원 팔 두 개의 내부 결합
z = (1−w_ebm)·z + w_ebm·p_EBM                  ← 팀원 EBM 팔
z = c_aa·lg(p_AA) + T70·lg(p_T70) + (…)·z      ← 우리 팔 두 개
p = expit(alpha·z + beta_skew·z² + beta_cube·z³ + d_adj + Σ 오프셋 축)
```

계수는 전부 `blend.json` 에 있고, 그 유도 근거는 §4 에 적었다.

## 4. 사후 변환 상수의 출처

모든 상수는 **로컬 측정에서 나왔고**, 리더보드는 그 상수의 *크기*를 정하는 데만 썼다. 각 상수가 무엇을 반영하는지와 어떤 계산으로 보정됐는지는 `blend.json` 의 각 `*_provenance` 키에 사실대로 적혀 있다. 주요 축:

| 상수 | 무엇을 반영하나 | 어떻게 정했나 |
|---|---|---|
| `alpha` · `beta_skew` | 로짓 보정 곡선의 1·2차항 | 로컬 out-of-time 잔차면에서 유도 → LB 측정 후 2차식 꼭지점 보간 |
| `beta_cube` | 같은 곡선의 3차항 | LB 2점(+0.42 / −0.20)으로 2차식 완전해 → 꼭지점 +0.137~0.141 아래 착륙 |
| `w_v6` | 두 주력 팔의 결합비 | 부모에서 미적합(`w_fitted: false`)이었다. 0.70→0.75 한 점 측정 + 라벨 없는 곡률로 꼭지점 산출 |
| `coldmiss_shift` | 경력 50구 이하이고 동결 Q 표에 (투수, 타자손) 칸이 없는 행의 보정 | 2023 true-OOT 잔차에서 크기·부호 산출 → LB 1점으로 꼭지점 착륙 |
| `unseen_state_bundle` | 학습에서 드물게 본 결정적 상태 묶음(아웃카운트·주자·이닝 상하 등) | 2폴드 시간분할 게이트 통과 후 LB 2점으로 부호·꼭지점 확정 |
| `ctrl_asof_*` 8축 | 투수·타자의 as-of 한복판 비율 등 원본 열 기반 오프셋 | 로컬 부호 스크린 → LB 프로브로 진폭 |

각 축의 LB 측정 이력 전량은 `submissions/CV_LB.md` 에, 매 후보의 게이트 기록은 `submissions/GATES_*.md` 에 있다.

## 5. 규칙 2-4 준수

추론은 행 단위로만 이뤄지며, 어떤 행의 예측도 다른 test 행의 값에 의존하지 않는다. 매 후보마다 기계 검사로 확인했다.
- **전체 셔플 게이트**: test 행 순서를 무작위로 섞어 추론한 뒤 원래 순서로 되돌려 원본과 대조
- **내용/위치 분리**: 문제 행의 값·인덱스를 고정하고 나머지 전 행을 두 프레임 어디에도 없는 행으로 전량 교체 → Δ 가 정확히 0.0
- **항등 앵커**: 새로 넣은 상수를 부모 값으로 되돌려 패키지를 통째로 다시 만들면 출력 CSV sha256 이 부모와 일치
