## 가설
exp_001 예측의 +1.7pp 과대(base rate 하강 미반영)를 후처리 보정으로 잡으면 fold_2024 valid-R Brier가 개선된다.

## 셋업
- exp_001 저장 모델(`~/SungjinPark/experiments/exp_001/model_fold_{2023,2024}.txt`)로 valid 예측 재생성 — **재현 검증 통과** (fold_2023 R 0.250527, fold_2024 R 0.249337, exp_001 metrics.json과 소수 6자리 일치).
- **평가 무결성**: 보정 파라미터를 fold_2024 valid에서 적합한 후보 없음. A/B는 fold_2023 valid-R(해당 fold 모델 예측), C는 train 통계만 사용.
- CPU 예측만, num_threads=4, 총 0.19분 (병렬 실험 배려).

## 후보 정의
- **A. 상수 로짓 오프셋**: fold_2023 valid-R에서 Brier 최소화로 δ 적합 → fold_2024에 적용. δ = **−0.1207**.
- **B. isotonic**: fold_2023 valid-R에서 p→y 적합(65 knots, clip) → fold_2024에 적용.
- **C. base rate 추세 앵커** (valid 완전 미참조): R리그 연도별 성공률 2019~2023(전부 fold_2024 train 연도)의 선형 추세(기울기 −0.0116/년) 외삽 → r̂₂₀₂₄=0.4844. 앵커 m = fold_2024 모델의 2023년 R **train** 행 예측 평균 0.5081. δ_C = logit(r̂)−logit(m) = **−0.0946**을 행별 상수 적용 — test 예측 분포 참조 없음(규칙 2-4 안전).
- (참고) oracle 오프셋: fold_2024 valid-R 자체에서 in-sample 적합한 상한선. **후보 아님.**

## 결과 — fold_2024 valid-R (n=223,497, 실제 base rate 0.4897)

| 후보 | Brier | Δ vs 원본 | BSS | AUC | pred_mean (보정 전 0.50637) |
|---|---|---|---|---|---|
| exp_001 원본 | 0.249337 | — | +0.00223 | 0.5341 | 0.50637 |
| A. 로짓 오프셋 (2023적합) | 0.249234 | −0.000103 | +0.00264 | 0.5341 | 0.47639 |
| B. isotonic (2023적합) | 0.251532 | **+0.002195 악화** | −0.00655 | 0.5310 | 0.46980 |
| **C. 추세 앵커 (train-only)** | **0.249104** | **−0.000233** | **+0.00316** | 0.5341 | 0.48287 |
| (참고) oracle in-sample 상한 | 0.249058 | −0.000279 | +0.00334 | 0.5341 | 0.48964 |

- **C가 최선**이며 oracle 상한(−0.000279)의 84%를 valid 무참조로 회수. BSS는 +0.0022 → +0.0032 (+42%).
- A는 개선하지만 과보정: fold_2023의 갭(+3.0pp)이 2024 갭(+1.7pp)보다 커서 δ가 과대 → pred_mean 0.4764로 실제(0.4897) 아래로 관통. 연도별 갭 크기가 불안정하다는 신호.
- **B 기각**: fold_2023 valid의 보정 형상이 2024로 전이되지 않음 — OOF에서 명확히 악화 + AUC 훼손(구간 동률화). 저신호 문제에서 연도 간 isotonic 전이는 위험.
- Calibration 10분위(metrics.json): 원본은 전 구간 상방 이탈, C 적용 후 중·상위 분위가 대각선에 근접(예: bin7 0.5301→0.5065 vs 실제 0.5099). 하위 1~2분위는 여전히 소폭 과소 — 상수 이동의 한계.

## 결론 — **C안 채택** (A 부분 유효, B 기각)
fold_2024 valid-R Brier 0.249337 → **0.249104** (BSS +0.00316). 가설 채택 — 보정 갭은 실재하며 train-only 추세 앵커만으로 대부분 회수된다.

## 본번(2025 추론) 적용 형태 권고
1. **1순위 — C안 그대로**: train의 R리그 연도별 성공률 2019~2024로 선형 추세 재적합 → r̂₂₀₂₅ (약 0.478 수준 예상). 앵커 m = 최종 모델(train≤2024)의 2024년 R train 행 예측 평균. δ = logit(r̂)−logit(m)을 **상수로 하드코딩**해 행별 적용 — test의 다른 행·분포 참조 없음, Phase 3 재현 자명.
2. A안의 본번 형태는 "fold_2024 valid에서 δ 적합 → 2025 적용"인데, 이 구조의 유효성은 본 실험의 fold_2023적합→2024적용 delta(−0.000103, 과보정 동반)로 추정한 것임 — C보다 근거가 약하고 이득도 작아 차순위.
3. 리스크: C의 선형 외삽은 하강이 감속하면(2022→2023 −0.06pp에 불과) 과보정 위험. r̂₂₀₂₅이 0.47 아래로 나오면 최근 2년 추세와 교차 검토 후 δ 상한 캡 고려. Brier는 최적점 부근에서 평평하므로(oracle과 C의 차 0.00005) 소폭 오차는 치명적이지 않음.
