**날짜** 2026-08-09 · **학습 없음** (exp_037 저장 예측 위 사후 변환, 계산 **0.41분**, 벽시계 약 11분 — ETA 15~20분 대비 단축)

## 1. 결론 한 줄

**세 축은 독립이 아니다.** 오프셋·캘리브레이션 **모두** 팀원 피처 위에서 이득이 줄었고(**−10.84157 / −11.95141점**, 3/3 시드 부호 일치), 캘리브레이션 쪽은 **혼입 없이 겹침이 확인**된다(피처가 예측 수준 갭의 **33.6%**를 이미 닫았다). 오프셋 쪽 감소는 "겹침"과 "β 오적합"으로 **분리되지 않는다.**

## 2. 설계

2 base(`R0` 47열 / `L_no_sit` 63열) × 3 시드(42·7·2024) × 4 변환 = **24 평가.**

| | 변환 |
|---|---|
| T0 | 없음 (원본) |
| T1 | 오프셋만 — `clip(p + β·d, 1e-6, 1−1e-6)`, `S400_self`, k=400, β **0.59072** |
| T2 | 캘리브레이션만 — `sigmoid(logit(p) + γ)` |
| T3 | 오프셋 먼저, 그 위에 γ (배포 순서) |

γ는 후보 N 레시피(시드별 평균정합 해 → 3시드 평균 → 6자리). **T2의 γ는 원본에서, T3의 γ는 오프셋 출력에서** base별로 따로 풀었다. 2024 실제 성공률은 `train.csv`에서 직접 계산: **0.4861049201797189** (253,507행).

## 3. 무결성 — 게이트 넷

**(a) 예측 출처** — 6개 `.npy` sha256이 exp_037 `res/*.json` 기록값과 일치, 재계산 Brier가 기록값과 5e-12 안쪽, `any_argmin_at_cap` 전부 False.

**(b) β 재현** — 공급 블록(exp_031 stage-3, 2022·2023 × 시드 42·7, sha 대조)에서 **재적합해** 0.59072를 그대로 얻었다. 인용이 아니라 재계산이다.

**(c) 🟢 뜻밖의 재현 게이트 — R0가 후보 M·N의 로컬 수치를 정확히 되짚었다**

exp_037의 `R0` fold_2024 예측 3개는 exp_030 stage-2와 **sha256 동일**(`ef4bafad…` / `d3c606b0…` / `aa999bb9…`).

| 양 | 이번 측정 | `BUILD_PLAN_N.yaml` 기록 |
|---|---|---|
| R0 @T1 Brier (후보 M base) | `0.24790019374272065` | `0.24790019374272065` |
| R0 @T3 Brier (후보 N base) | `0.24784463562970935` | `0.2478446356` |
| T3 − T1 이득 | **+22.24042점** | **22.24042점** |
| 시드별 | 23.17855 / 20.66380 / 22.87892 | 동일 |

**제출한 후보의 로컬 수치를 다른 경로로 재현했다.**

**(d) 리크 표면** — `d`는 `dev_k.py`(sha `e1cd86dd2795a4d1…07a0d9`, exp_033/exp_036 바이트 승계)의 **전개형** `d = (s − n·overall)/(n + k)`, 리그 항 `L·(k/(n+k))`. 2024 행이 본 표의 최대 소스 시즌 = **2023으로 코드 내 assert**, 전 행 동일 소스. 셀 적중 78.501%, 미적중 행 `d == 0.0` assert. **clip 발동 24 평가 전부 0회**(`max|β·d| = 0.045615` — 확률 단위 이동폭이며 행별 방향을 모르므로 **점수로 환산하지 않는다**).

가중 확인: `0.881621 × 26.0582 + 0.118379 × (−13.0601) = 21.4278` ≈ 측정 +21.4274 ✓
