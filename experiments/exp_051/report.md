- the one: R 갈래 셀 4개 입력 47→63열. 종속 재산출: OOF 4열 재생성(같은 forward-chaining·같은 시즌 블록·**같은 pinned iter** {mid 577, rev 1346, both 449, wayoff 897} — `build_AH/local_reference_AH.json`의 `per_seed.<seed>.run.cell_iter_used`에서 실행 중 읽음, 전사 없음), 스태커 재적합(입력 67열·순서 exp_048 A1 그대로, 1400 고정).
- 대조군: exp_048 A1 — 재학습 없음. 저장 예측 sha 대조 3시드 전부 일치(sha_match True, abs_diff_brier 0.0).
- 파생 규약: 부모 `local_ref_stack.py`(sha 1993f63e…)를 등록 치환 24건으로 파생(`src/patch_train51.py`, 치환마다 앵커 1회 assert, diff `src/train51.diff`).

## 관측 (측정값)
1. **셀 4개 전부 자기 지표는 좋아졌다** (3시드 평균, 47→63): AUC mid 0.5725→0.5787 / rev 0.5797→0.5834 / both 0.5432→0.5529 / wayoff 0.6010→0.6016, logloss 4개 전부 감소. **ins gain 점유율**: mid 26.5% / rev 26.4% / both 25.4% / wayoff 12.8%.
2. **OOF 이동량** (valid 행, 시드 평균): p_rev_only mean|Δ| 0.0156 (p99 0.063, corr 0.924) / p_mid_only 0.0092 (corr 0.901) / p_wayoff 0.0056 (corr 0.984) / p_both 0.0031 (corr 0.873). 스태커 입력이 실제로 크게 달라졌다.
3. **T1의 라운드 곡선이 내려간다** — 655 > 1000 > 1400, 세 시드 일관. ⚠️ **관측으로만 적는다**: 스태커 반복 축은 fold_2024와 LB의 부호가 반대로 실측된 축이다(현재 베스트 표 ⛔ 항목). "655가 낫다"는 결론이 아니다. 참고로 대조군 A0도 같은 방향(655>1000>1400)이었다.
4. **딸림 변인 — 63열 셀의 곡선 argmin이 pinned iter보다 훨씬 작다** (s42: rev 675 vs 1346, both 300 vs 449, wayoff 650 vs 897, mid 575 vs 577; argmin_at_cap 아님). 규약대로 iter 재선택은 하지 않았고 기록만 한다.
5. 스태커(67열)에서 `ins_p_success`는 여전히 gain 상위(s42 2위) — 셀에 넣어도 스태커 직접 입력의 순위는 유지됐다.

## 해석 (관측과 구분)
같은 16열이 셀과 스태커 양쪽에 들어가자 OOF 4열이 ins와 중복 정보를 실어 나르게 됐고, 셀 개선분이 스태커 눈금에서 회수되지 않았다. pinned iter가 63열 셀 기준으로는 argmin의 약 2배 지점(과잉 학습 구간)이라는 점이 악화의 한 경로일 수 있으나, **iter만 바꾼 대조가 없으므로 이 조합의 효과로만 서술한다** (exp_034 전례상 iter 재적합 자체도 −23.02를 잃었다).
