## 2. F 세그먼트

**무너진 안 없음** — valid_F Brier 0.24793~0.24813으로 오히려 valid_R보다 좋다(마스크 전 안 공통 적용 덕). 다만 F 예측평균이 실제(0.4593)보다 +0.93~1.50pp 과대하고, **이 갭의 크기 순서가 valid_all 순위와 정확히 일치**(D +0.93 → A +1.50). 남은 F 이득은 판별력이 아니라 **보정**에 있다.

## 3. 최우수안 D의 성격 — 견고성이지 절대 우위가 아님

**오라클 iter 기준으로는 B(0.248193) < D(0.248247)로 순위가 뒤집힌다.** D가 정책 하에서 1위인 이유는 곡선이 평탄해 직전 fold 승계 iter가 잘 전이되기 때문(정책 비용 +0.000014, 타 안의 1/5~1/8). **"D가 본질적으로 우수하다"고 서술하면 안 된다.**

## 4. 핵심 관찰

1. **ID 처리는 거의 무관했다.** A(ID 수치) 0.248310 = B(ID 완전 제거) 0.248310 ≒ C(TE) 0.248314 — 3안 폭 **4e-6**. 반면 exp_007 대비 개선은 −0.00075로 **약 200배**. 가설 전반부(ID 과적합이 원인)는 맞았으나 **처방은 "ID를 어떻게 넣느냐"가 아니라 "ID가 과적합할 수 없게 규제하느냐"** 였다.
2. **C의 TE는 gain 31.6%(단일 최대 28.2%)를 먹고 이득 0** — `asof_pitcher_success_rate`와 같은 (prev_sum, prev_n)에서 파생된 재포장. **기각 권고.**
3. **exp_005-C 후보정이 이제 해롭다**(C raw 0.248329 → 보정 0.248364). exp_007 계보의 보정 단계는 이 모델에 **승계 금지**.
4. P4-all이 4안 모두에서 P4-R보다 우수(−0.000015~−0.000091). ID gain 점유율 A 1.88% / B 0% / D 1.01%.

## 5. 결론

**D 채택 — valid_all 0.248261, 환산 619.0.** RF 초과(−0.000508)로 exp_008의 제출 정지 조건 해소.
단 목표선 1,061점(BSS 0.01061)에는 여전히 **1.7배 부족**(현재 0.00619).

## 6. 특이사항·의심 지점

- 에러·경고 없음. cap 미도달(어떤 fold도 argmin이 상한 2000/3000에 안 닿음).
- **안 사이 격차 4e-6~5e-5는 단독 우열 근거로 삼기엔 얇다.**
- 리크 자체점검 통과: C의 TE는 주최측 `asof_rate × asof_n`에서만 파생돼 test 재현 가능, 자체 expanding shift(1) 대조에서 **n 차이 정확히 0**(147만 행), sum 차이 최대 0.0076(제공 컬럼 반올림). k=500은 fold_2023에서만 튜닝. prior는 test에서 2024말 값 동결, 신규 투수 폴백.
- **미이행 이월**: 인코더 카테고리가 전체 파일 기준 — exp_001 감사의 "train-only category vocab" 여전히 미이행, 제출 파이프라인에서 처리 필요.
- **저장된 `model_*_fold_2024.txt`는 P4-R iter로 잘려 있다**(D는 375). 제출 시 재학습 필요.
- ⚠️ **정정(2026-08-05, 감사 지적)**: 위 문장의 원래 표현은 "제출 시 `num_boost_round=750`"이었으나 **틀렸다.** 750은 fold_2023의 argmin으로, fold_2024를 *보고*할 때(0.248261 / 619.0) 정직한 값이다. 최종 모델은 **≤2024로 학습**하므로 P4 정책상 마지막 가용 fold가 fold_2024이고, 그 argmin인 **1550**(Brier 0.248247)을 써야 한다. 실제 제출물(`submissions/A_lgbm_D/`)은 1550으로 빌드됐다.
- ⚠️ **함의**: 배포 스펙(iter 1550)의 로컬 등가는 **≈624.6**이지 619.0이 아니다. 또한 §3에서 지적했듯 오라클 iter 레짐에서는 D가 1위가 아니다(B 0.248193 < D 0.248247) — **A는 D가 최선이 아닌 레짐의 iter로 배포된다.** LB 결과 해석 시 이 점을 감안할 것.
- exp_009·exp_011과 서버 동시 사용(load 최대 24.8/40코어), num_threads=6 준수.
