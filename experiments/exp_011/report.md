## 2. 가설 검증 — 저표본에서 효과가 크다 (예측대로)

`asof_pitcher_n` 구간별 M0 → MA delta:

| n 구간 | 행수 | delta |
|---|---|---|
| n = 0 (완전 신규) | 81 | **−0.001569** |
| (0, 100] | 7,908 | −0.000207 |
| (100, 300] | 12,649 | −0.000056 |
| (300, 1000] | 38,096 | −0.000038 |
| (1000, 3000] | 69,995 | +0.000007 |
| (3000, ∞) | 124,778 | −0.000056 |

**표본이 적을수록 이득이 크다** — 수축의 이론적 예측과 정확히 일치. n=0 구간은 −0.0016으로 전체 평균의 40배.

리그별로 쪼개면 **F리그에서 효과가 3~4배 크다**:

| 구간 | R delta | F delta |
|---|---|---|
| n ≤ 100 | −0.000081 | **−0.000362** |
| 100 < n ≤ 1000 | −0.000019 | −0.000124 |
| n > 1000 | −0.000030 | −0.000071 |

F리그에 저표본 투수가 몰려 있기 때문(n≤100 구간의 F 비율 0.498 vs 전체 0.12). 주 지표를 valid_all로 바꾼 것이 이 실험의 가치를 드러냈다 — valid_R만 봤다면 −0.00003 수준으로 묻혔을 이득이다.

## 3. 핵심 관찰

1. **수축값은 원본을 대체하지 않고 보완한다.** raw rate 10열을 제거한 MC(0.248456)가 대조군 M0(0.248430)보다 나쁘다. 모델은 "수축된 추정치"와 "원본 + n" 둘 다 필요로 한다.
2. **파생 7열(매치업 로그오즈 등)은 이득 없음** — MB(0.248398)가 MA(0.248389)보다 약간 나쁘다. exp_009·exp_012와 같은 패턴(열 추가의 한계효용 음수).
3. **game_type별 prior 분리는 불필요** — 통합 prior가 우수. F의 라벨 체제가 다르다는 우려는 수축 단계에서는 문제되지 않았다(마스크가 이미 구체제 F를 제거했기 때문으로 추정).
4. **마스크 효과 재확인**: RB(마스크 없음) 0.248659 vs MB(마스크) 0.248398 = **−0.000261**. 수축과 독립적으로 마스크가 계속 유효하다.

## 4. test 재현성 검증 (`src/infer_stub.py`, 5행 스텁 실측)

- cold-start 실증: `TEST_005332`(asof_pitcher_n=0)에 수축값 0.523766 = prior가 정확히 들어감. **sentinel이 아니라 리그 사전확률로의 수축**이므로 규율 준수.
- ⚠️ **S5(전체 데이터 적합)는 미완료** — 에이전트 종료 시점에 진행 중이었다. 제출 스펙으로 채택 시 재실행 필요.

## 5. 결론

**소폭 채택 — 단 단독 제출 후보는 아니다.** MA(+16.4점)는 실개선이고 저표본 구간에서 이론과 일치하는 패턴을 보였으나, 같은 날 exp_010 D가 −0.000508(619.0)로 훨씬 큰 이득을 냈다.

**결합 가치가 본체다**: 이 실험의 이득은 **저표본·F리그 구간**에 집중돼 있고, exp_010 D는 규제 강화로 **전 구간**에서 이득을 냈다. 두 이득의 원천이 다르므로 **exp_010 D 스펙 위에 수축 10열을 얹으면 가산될 여지가 있다.**
