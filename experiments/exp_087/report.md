### 4.1 G2 — 신규 fit 이 `random_seed` 만 다른가 ✅ **통과 (10 fit)**

신규 시드 1·3 의 5모델 전부에서 `get_all_params()` 가 **`random_seed` 하나만** 다르다. 트리 수·피처 순서도 동일.

🔴 **첫 실행은 FAIL 이었고 원인은 신규 시드가 아니라 게이트였다.** `model_info.params` 안에 `flat_params` 라는 **같은 파라미터의 직렬화 사본**이 있어서 `random_seed` 가 바뀌면 그것도 따라 바뀐다 — 첫 판이 **변인 하나를 둘로 세었다**.
고친 판은 `flat_params` 안으로 한 단계 내려가 **거기서도 `random_seed` 말고는 다른 것이 없어야 한다**고 요구한다(실측: 오직 `random_seed`, 42→1).
⚠️ 이것은 **판정 문턱 변경(S8)이 아니라 기계 검사 명세의 오류 수정(S27)** 이고, 고친 판이 원판보다 **더 많은 증거를 요구한다**.

**웨이브 1이 G1 을 함께 태운 이유**: 쿼터가 20코어라 단독 G1 웨이브는 12코어를 90분 놀린다. 게이트의 목적(나머지 13시드 앞에서 멈추는 것)은 그대로다 — 실패하면 `STOP_G1_FAILED` 가 생기고 `run_rest.sh` 가 스스로 거부한다.

## 5. 부가 측정 — 시드 곡선

배포 fit(≤2024)은 2024 로 채점할 수 없으므로 **곡선은 exp_037 의 fold_2024 3시드 벡터에서 유도**했다.
세 벡터면 충분한 이유: 묻는 법칙 자체가 교환가능성 법칙이다. `p_ir = μ_r + ε_ir` 이면 `E[Brier_n] = Brier_∞ + V/n` 이고 이것이 `score(n) = a − b/n` 의 정확한 형태다. `V` 는 시드 간 불편분산으로 추정된다.
🟢 재계산한 seed-42 Brier 가 exp_037 기록과 **|Δ| = 0.0** 로 일치한다.

| 면 | n | `V` | **`b`** (점) | 3→18 (점) |
|---|---|---|---|---|
| `valid_all` | 253,507 | 2.076082e-05 | **8.3107** | +2.3085 |
| **`valid_F`** | 30,010 | 3.337191e-05 | **13.3591** | +3.7109 |
| `valid_R` | 223,497 | 1.906747e-05 | 7.6329 | +2.1202 |

**config 의 질문 — `b` 가 R 쪽 35.99 와 비슷한가? 아니다.** `valid_F` 에서 **13.36**, R 쪽 값의 **0.37배**다.
(그리고 exp_077 이 이미 *"AA81 계수 35.99 를 다른 팔로 옮기면 틀린다"* 를 실측으로 적어 뒀다 — 이 비교는 진단이지 예측이 아니다.)

**추론 시간 대 시드 수 기울기: 0.143초/시드** (1스레드, 잔차 sd 7.96초 — 잡음 아래).

**시드 평균 예측의 이동폭 — 유도 + 실측.**
3시드 집합이 더 큰 집합의 부분집합이므로 `Var(p̄₃ − p̄ₙ) = V·(1/3 − 1/n)` 이다.
그리고 **실측**: F 시드 3개 패키지와 5개 패키지를 **출하 `script.py` 로 같은 프레임(`cov`, 245,789행)에 돌려** 최종 제출값을 비교했다.

| | 값 |
|---|---|
| **R 행 216,689개** | **max\|Δ\| 정확히 0.0 · pearson r = 1.0 · 움직인 행 0** |
| F 행 29,100개 | 전부 움직임 · pearson r = 0.99998659 |
| F 행 rms\|Δ\| | **2.796e-04** |
| F 행 max\|Δ\| | **2.253e-03** |

🔑 **R 행이 한 톨도 안 움직인 것이 이 측정의 대조군이다** — F 브랜치는 R 행에서 가중치가 0이라는 설계가 배포 경로에서 확인됐고, 동시에 **패키지 편집이 다른 곳을 오염시키지 않았다**는 뜻이기도 하다.

**유도와 실측이 맞는다.** stage-2 에서 0.5 믹스 후 예상 이동 sd 는 3→5 에서 **1.055e-03** 인데 실측 최종값은 **2.796e-04** — 감쇠 **0.265**다.
최종 제출값은 stage-2 혼합 확률이 아니라 stage-3 오프셋·stage-4 감마를 지나 **로짓공간에서 우리 AA 팔 지분 0.3** 으로 블렌드된 값이므로 **0.3 이 기대값**이고, 0.265 는 그것과 맞는다.
→ **§6 의 도달 산술이 독립적으로 확인됐다.**

같은 배율로 3→18 을 외삽하면 F 행 rms **4.04e-04**, max **3.25e-03**.

🔴 **이건 예측이 얼마나 움직이는지이지 점수가 얼마나 움직이는지가 아니다** (S9). 점수는 §6.

## 6. 이 축이 얼마짜리인가 — LB 로 눈금이 잡힌 유일한 자

로컬 정직면으로 크기를 재지 말라는 지시(S78 의 54배 사고)를 지키면서 크기를 말할 길이 하나 있다: **같은 기전의 축이 이미 LB 로 측정돼 있다.**

- 후보 **AV** 가 **R 브랜치 시드 9 → 18** 로 **LB +0.8716523199** 를 받았다.
- 평균 법칙에서 `n → 2n` 이득은 `σ²/(2n)` → **`σ²_R`(프레임·LB 눈금) = 18 × 0.87165 = 15.68974점**.
- `CV_LB.md` 는 그 자리에서 **이 축을 닫았다** — 18→∞ 가 다시 +0.87165 뿐이고 문턱 3점 아래라서.

F 브랜치로의 이식은 **가정이 아니라 비**다. 두 브랜치 모두 fold_2024 에서 같은 3시드·같은 253,507행의 stage-2 벡터가 있어 같은 방식으로 분산을 재고 **비**를 쓴다 — fold_2024↔배포 배율도, 블렌드·보정 전이도, 둘에 똑같이 걸리므로 **비에서 나눠진다**. 나눠지지 않는 것은 믹스에서의 자리뿐이다:

| | R 행 (88.162%) | F 행 (11.838%) |
|---|---|---|
| R 브랜치 가중 | 1.0 | 0.5 |
| **F 브랜치 가중** | **0** | 0.5 |

| 양 | 값 |
|---|---|
| `V_F` (F 행 위) | 3.337191e-05 |
| `V_R` (F 행 위) / (R 행 위) | 1.379166e-04 / 9.482178e-05 |
| `V_F / V_R` (F 행 위) | **0.24197** |
| `reach_F` / `reach_R` | 9.876363e-07 / 8.767845e-05 |
| 프레임 도달 비 | **0.0112643** |
| **이식된 `σ²_F`** | **0.17673점** |

**F 브랜치 시드 축의 값:**

| 시드 | 이득 (LB 점) |
|---|---|
| 3 → 6 | +0.02946 |
| 3 → 9 | +0.03927 |
| 3 → 12 | +0.04418 |
| **3 → 18** | **+0.04909** |
| **3 → ∞ (축 전량)** | **+0.05891** |

🔴 **축 전량이 0.059점이다.** 목표까지 남은 거리는 **+34.01**, 장부가 *"문턱 3점 아래"* 라며 **닫은** R 브랜치 시드 축의 남은 몫은 **+0.87165** 였다.
**이 축은 이미 닫은 축보다 15배 작다.**

**민감도**: R 쪽 비교군을 exp_030 의 C5B3 벡터로 바꾸면 `σ²_F` 가 0.55022 로 올라 3→18 이 **+0.15286** 이 된다. 그 벡터는 배제하는 것이 맞다 — exp_030 의 fold_2024 스태커는 **481라운드에 고정**(자체 기록된 검열 결함)인데 배포는 1400라운드라, 시드 산포를 약 3배 낮게 보고해 F 브랜치를 그만큼 좋게 보이게 한다. **어느 쪽을 써도 0.05~0.15점이다.**

### 6.1 부산물 — 분산감소형 축의 로컬→LB 전달률이 하나 측정됐다

같은 계산이 **검증 가능한 부산물**을 하나 낸다. R 브랜치의 fold_2024 프레임 분산을 LB 점으로 환산하면 **35.09849점**인데, AV 의 실제 LB 측정이 함의하는 값은 **15.68974점**이다.

> **로컬 fold_2024 브랜치 분산 → LB 전달률 = 0.4470** (분산감소형 축)

이것이 재는 것은 두 가지의 곱이다 — ① fold_2024(≤2023 학습) 대 배포(≤2024 학습)의 분산 차이(배포가 학습행이 많아 시드 산포가 작다 → <1) ② stage-2 에서 최종 점수까지의 전달.
S4 의 `0.068`(팔 Δ → 블렌드 Δ)이나 exp_077 의 `0.2173`(팔 이득 → 블렌드)과 **분해 지점이 달라 직접 비교할 수 없다.** 같은 자리에서 다시 쓸 때만 유효하다.

⚠️ **이 추정이 기대는 것 셋**: ① 평균 법칙 ② AV 앵커가 오늘 패키지에도 유효하다는 것 — 우리 AA 팔의 바깥 지분은 후보 AK 이래 **0.300 으로 불변**이고 AV 는 그 뒤라 같은 자리다. 다만 그 사이 `alpha`·오프셋·파트너 팔이 움직여 `r0` 는 달라졌다(S2) ③ `V_F/V_R` 비가 시드 3개씩에서 나왔다는 것. **비가 10배 틀려도 0.6점이다.**
