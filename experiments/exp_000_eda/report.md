## 0. 데이터 개요·키 구조 [실측]

| 파일 | 규모 | 내용 |
|---|---|---|
| train.csv | 1,475,092행 × 49컬럼 | 2019~2024, 투구 1행, 타깃 `control_success` 포함 |
| test.csv (스텁) | 5행 × 48컬럼 | 2025년. 컬럼 구조 train과 완전 동일(타깃만 제외, 순서까지 일치) |
| trackman_history.csv | 1,793,078행 × 30컬럼 | 2019~2024 투구 물리량. **train과 ID 체계 분리** (§4) |

- `row_id` 유일, 완전 중복 0행. 타깃 1: 772,603 / 0: 702,489 (전체 성공률 **0.5238**).
- **행 단위 = 투구 1구**, train은 각 투수의 **전 투구를 빠짐없이** 담는다: 파일 순서에서 투수별 `asof_pitcher_n` 증분이 **100% 정확히 +1** (타자도 동일).
- **파일 순서 = 주최측의 정식 시간축**: `asof_pitcher_success_rate[t] × n[t] == Σ control_success[<t]` 가 표본 투수 12명 전원에서 정확히 성립. asof 피처는 이 파일 순서의 expanding-shift(1) 집계다.
- 단, 시즌 내부 배치는 **[R리그 경기 시간순] 뒤에 [F리그 경기 시간순]을 이어붙인 구조** (월 역행 6곳 전부 R→F 경계). 실제 달력 순서와 다르지만 asof도 이 순서로 계산돼 있으므로 **우리 추가 피처도 파일 순서를 시간축으로 쓰면 주최측과 리크 경계가 정확히 일치**한다.
- train에 **경기 ID·날짜 컬럼 없음.** (season, month, dow, game_type, 팀페어) 변화점으로 블록 복원 시 **4,821경기** (R 702~720/시즌 = KBO 1군 풀시즌, F 76~104/시즌 = 퓨처스 일부 표집).
- `game_type`: R(1군) 1,314,088행 / **F(퓨처스 추정[추측], 팀ID 22·23·25가 F 전용) 161,004행**. test 스텁은 R뿐.
- 시즌 경계에서 asof 카운터 **리셋 없음**(1,468/1,468 이월) — 커리어 누적.

## 1. 전략 1장 "확인 필요 5항목" 답

### ① 제구 성공의 정의 — 카운트 의존성 약함. "의도반대(reverse)·가운데/위험(middle) 코스가 아닌 투구"에 가까움
- [실측] 카운트 12상태 성공률 편차가 매우 작음 (R전용 0.487~0.527, 4pp). 존 통과율의 실제 카운트 편차(±15pp+)와 전혀 다름 → **카운트별 의도에 적응하는 정의** [강한 정황].
- [실측] 커리어 항등식 (500구+ 투수 465명): `success + reverse + middle ≈ 0.900 (±0.024)`. OLS `success ≈ 0.944 − 0.78·reverse − 0.68·middle − 0.30·ball − 0.07·strike` (R²=0.875). corr(success, reverse) = **−0.874** → **실패 ≈ 의도반대 ∪ 가운데/위험** (범주 겹침 ~10%).
- [실측] success ≠ strike (corr 0.088, success가 평균 +9.3pp 높음) — 의도된 볼(유인구)이 성공에 포함되는 정황.
- 함의: 카운트 범주형은 넣되 지배 피처 아님. **투수 고유 성향(asof success/reverse/middle)이 최대 신호** (단일 corr 0.084).

### ② 현재 투구 구종 — test에 없음 [실측]. 과거 구종 믹스(asof_pitcher_fastball/breaking/offspeed_rate)만 제공.

### ③ 지표 — Brier Skill Score (확정). train base rate 0.5238 → 기준 Brier ≈ 0.2494. 2025 r은 추세상 0.48 부근 추정 [추측] → 보정이 점수에 직결.

### ④ ABS/라벨 체제 — 급변은 F리그, R리그는 완만 하락 [실측]

| season | R | F |
|---|---|---|
| 2019 | 0.5495 | 0.6892 |
| 2020 | 0.5269 | 0.5878 |
| 2021 | 0.5128 | 0.7038 |
| 2022 | 0.5037 | 0.7087 |
| 2023 | 0.5031 | **0.4729** |
| 2024 | 0.4897 | 0.4593 |

- R: 매년 ~1pp 완만 하락, **2024(ABS 원년) 단절 없음** (월별로도 특이 없음).
- **F는 2023년 −24pp 폭락** — 퓨처스 라벨 산출 체제 변화 추정 [추측].
- 함의: 2019~2022 F행(~10.5만)은 다른 라벨 체제 → 제외/가중/피처화 실험 변수. R base rate 하강 추세 → 예측 평균 앵커링 주의, fold_2024로 보정 검증.

### ⑤ 규모 — 147.5만 행(시즌 ~24.6만), 투수 792, 타자 830, 팀 13(1군 10 + F전용 3). GBDT 주력 확정, TabPFN 주력 불가 판단 유지.

## 2. asof_* 사전집계 피처 (중점 2)

- [실측] 정의 완전 해명: 파일 순서 기준 커리어 expanding(현재 행 제외), 시즌 리셋 없음, R+F 통합 집계, `rate×n`으로 분자까지 정확 복원 가능.
- [실측] 결측 구조 정직, sentinel 채움 흔적 **없음**:
  - `asof_pitcher_*` 결측 792행 = 각 투수의 최초 투구(n=0)와 1:1 일치 (타자 830행 동일).
  - `asof_pitcher_prev{1,3,5}_game_*` 결측 29,185행(1.98%) = 투수의 데이터 내 **첫 경기 동안** (해당 행 asof_n ≤ 150).
  - 0/−1 스캔(`profile/sentinel_scan.csv`): 의심 패턴 없음.
- **리크 경계 함의**: ① train 내 추가 집계는 파일 순서 + shift(1)이면 안전(주최측과 동일 경계). ② **test(2025)에서는 시즌 내 동적 집계 불가** (규칙 2-4 + 2025 데이터 부재) — 쓸 수 있는 것은 (a) 주최측 asof 컬럼(2025 시즌 내 누적 반영, 스텁에서 동일 투수 n=0→9 확인), (b) **2024년 말 기준 정적 선수 프로파일**뿐. → **train 학습 피처도 test에서 재현 가능한 형태로만 설계** (train/test 조건 일치).
- fold_2024 시 valid(2024) 행의 asof가 train 구간 정보를 포함하는 것은 주최측 공식 피처 구조로, 본번(2025)과 동일 — 리크 아님.

## 3. fold_2024 검증 정합성 (중점 3)

- [실측] season 컬럼으로 연도 분할 즉시 가능, 파일이 season 단조 정렬이라 경기 fold 교차 없음.
- [실측] 시즌당 신규 투수 63~110명(2024년 81/391명). **test 스텁 5행 중 2행이 train에 없는 투수, 2행이 train에 없는 타자**(asof 전부 NaN 행 포함) — cold-start fallback 필수 요건.
- test 행 순서는 셔플 [실측·5행 한정: TEST_000001=7월, TEST_000017=3월]. row_id 최대 035185 → 실 test ≥3.5만 행 [2025 R 풀시즌이면 ~22만 행, 추측].
- 주 지표는 **valid-R Brier** 권장(test는 R 추정), R+F는 참고치.

## 4. trackman 조인 (중점 4) — ID 직접 조인 불가, 경기 정렬로 사실상 완전 매핑 가능

- [실측] `pitcher_trackman_id`(906명, 50008~71775155) vs train `pitcher_id`(792명, 20700~24633) **교집합 0** — 별도 익명화 (타자 동일).
- [실측] 정규화(Top/Bottom→T/B, Right/Left→핸드) 후 상태키 99.76%가 trackman에 존재. (시즌,월,요일,총투구수) 시그니처로 **4,821경기 중 2,650경기 유일-유일 매칭**.
- [실측] **결정적 검증**: 매칭 샘플 경기 293투구의 (이닝·카운트·아웃·초말) 시퀀스 완전 일치, 투수 손 100% 일치, 경기 내 train→tm 투수 대응 완전 1:1 (8명). → 경기→행→**투수 ID 매핑 사전** 구축 가능, 유일 매칭에서 전파하면 전수 근접.
- **보너스** [실측]: `trackman_game_id` = `20190323-Incheon-1` 형식 — **실날짜·구장 내장** → 매핑 성공 시 train 경기에 실날짜 부여(등판 간격·연투·구장 피처, 단 train 전용).
- [실측] trackman 커버리지가 train보다 넓음(시즌당 909~1,091 vs 809~824경기). 물리량 결측 0.4~0.7%. 구속 km/h(평균 136), 릴리스 높이 m 단위.
- 안전한 활용 경로: 투수별 **2024년 말 정적 프로파일**(구속·회전수·릴리스 일관성 std·무브먼트·익스텐션·구종별 특성)만 train/test 공통 사용. train 전용 rolling 물리량은 test 재현 불가 → 본번 피처 금지.
- ⚠️ [판단 필요] 명세는 "1:1 결합 테이블 아님"이라 했을 뿐 매핑을 명시 금지하지 않았고 "투수 단위 요약값" 활용은 명시 허용. 코드 검증 대비 매핑 로직 투명 보존, scout으로 토크 모니터링 권장.

## 7. 예상 밖 발견·전략 수정 지점

1. **§4-⑤ 등판 내 시퀀스 피처 사실상 폐기** — train에 경기 컬럼 부재 + test 재현 불가. 시즌 내 동적 정보는 제공 asof가 유일 통로. 시간을 trackman 매핑·정적 프로파일로 재배분.
2. **§4-③ 피로 피처는 train 전용으로만 가능**(매핑 후 실날짜) — test에는 month/dow뿐이라 본번 피처 불가. 모든 피처는 "test 48컬럼 + 정적 테이블로 재현 가능한가" 선행 검문.
3. **포수 ID·심판 ID 없음** — §4-⑥ 해당 항목 폐기.
4. F리그 이질성(1번 항목) — 제외/포함/피처화 실험 변수. asof 카운터는 F 포함 계산임을 기억.
5. **경험 역상관**: 커리어 투구수 많을수록 성공률 낮음 (n≤50: 0.548 → n>6000: 0.513) [실측]. F·연도 교락 가능 [추측].
6. LI 역U자 (저 0.509 / 중 0.531 / 고 0.523) — 압박 단조 감소 가설과 다름.
7. 좌투 0.517 < 우투 0.526, 최저 매치업 좌투-좌타 0.491.
