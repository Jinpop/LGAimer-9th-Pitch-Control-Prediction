# exp_045 — NN 계열 개시 (엔티티 임베딩 + MLP): CatBoost와 섞을 값이 있는가

> ⚠️ **이 파일은 experiment-runner가 작성한 본문을 지휘자가 저장한 것이다** — 러너 쪽 하니스가 `.md` 쓰기를 막아 결과 메시지로 전달됐다. 내용은 러너의 것이고 지휘자가 요약·편집하지 않았다. 나머지 산출물(`metrics.json`, `ensemble_measurement*.json`, `res/`, `logs/`, `src/`)은 전부 러너가 직접 파일로 남겼다.

**결론: 기각.** 사전 등록한 네 구간 중 **4번**에 걸렸다 — 격차 225.44389점(> 150). 그리고 볼록성을 직접 재보니 **정확히 0**이었다. fold_2024에서 `w·NN + (1−w)·Cat`의 Brier 곡선은 w=0에서 단조 증가한다. **NN에 조금이라도 무게를 주면 진다.** 상관은 ρ=0.8455로 팀원 실측(0.8653)보다 더 독립적이었지만, **실력 격차가 다양성을 압도했다.**

> 환산: `점수 = 100000 × (1 − Brier/0.2498069)`. Brier가 원자료이고 점수는 그 기계 변환이다. 6자리 Brier에서 환산한 값은 ±0.20 불확실성을 가진다(Brier 1e-6 = 점수 0.4003). 아래 점수는 전부 14자리 Brier에서 환산했다.

## 1. 가설 대조

config 가설: *"NN은 단독 점수에서 질 것이다. 그러나 상관이 충분히 낮으면 섞을 값이 있다."*
**앞 절은 맞았고 뒷 절은 틀렸다.** ρ는 예상대로 낮았는데(0.8455 < 0.90), 격차가 225점이라 혼합 곡면의 꼭짓점이 w≤0으로 밀렸다.

- **w\* = 0.0 → 볼록성 0.0점, Cat 단독 대비 이득 0.0점**
- 사전 등록 식 `볼록성 > 격차/2` → `0 > 112.72195` → **불통과**
- **제약 없는 2차식 꼭짓점**도 시드별 −0.00492 / +0.02672 / −0.09016 (사실상 0 또는 음수). 그 꼭짓점 이득조차 0.00542 / 0.14972 / 1.73529점 — NN σ(27.68865)의 6% 미만
- 무보정 Cat 상대 꼭짓점 −0.08243 / −0.03270 / −0.17359, 이득 1.10463 / 0.16105 / 4.73305점
- **로짓공간 혼합 진단**(확인용): w\* 0.0 / 0.05 / 0.0, 이득 최대 0.04044점 → **혼합 기하 탓이 아니다**

### ④ fold_2023 적합 w → fold_2024 (정직한 추정치)

- fold_2023에서는 혼합이 **된다**: w\*=0.4, Cat 단독 대비 **+19.69266점**, 볼록성 **+30.23757점** (그 fold 격차는 −31.37826점뿐)
- 그 w=0.4를 fold_2024에 적용: vs 오프셋 Cat **−38.43013점** / vs 무보정 Cat(같은 조건) **−37.23965점**

③(상한)이 0점이고 ④(정직)가 −38점이므로, `upper_bound_warning`이 걱정한 "상한을 배포 기대값으로 서술하는" 실수를 할 여지 자체가 없다.

## 6. 🔴 NN 자체의 σ

| 측정 | σ (점) |
|---|---|
| **NN D0 fold_2024, 고정 epoch 8 (정직)** | **27.68865** |
| NN D0 fold_2024, fold별 조기 종료 (낙관적) | 7.67847 |
| NN D0 fold_2023 | 12.01999 |
| NN C3 fold_2024 (고정 epoch) | 40.50946 |
| 참고: CatBoost σ (exp_044, n=9) | 8.55113 |

**NN의 정직한 σ는 CatBoost의 3.2배.** config 우려가 실측으로 확인됐다. 조기 종료 σ(7.68)가 작아 보이는 건 각 시드를 자기 최소점에서 평가하기 때문이며 배포 상황의 σ가 아니다. **NN 판정에는 27.68865를 쓸 것 → 3σ 문턱 83.06595점.** 앙상블 이득 0~4.7점은 이 문턱의 5.7% 미만.

**부수 효과**: 고정 epoch 8 평균(537.82816)은 fold별 argmin(560.74663)보다 **22.91847점 낮다.** 이것이 fold-oracle(후보 O의 결함)을 피한 대가다.

## 11. 다음 제안 (지휘자 판단 대상)

사전 등록 4번 구간의 처방은 "NN을 더 키운다"인데, **단순히 키우는 방향은 이미 막혀 있다** — 용량을 늘린 구성(C4, D8, C5)이 전부 더 나빴고 개선은 전부 규제·축소에서 나왔다.

1. 🔴 **가장 값싼 후속: OOV를 정면으로 다루기.** ID 임베딩 대신 **투수를 asof 통계 프로필로 대표**하면 OOV가 사라진다. 다만 그건 CatBoost가 이미 쓰는 정보라 **다양성이 줄 위험**이 있다 — C3 관측(임베딩↑→ρ↓, 격차↑)이 그 상충을 보여준다.
2. **B3 셀 분해 NN.** config는 "유망 판정 뒤의 선택지"로 남겼는데 유망 판정이 안 났다. 그래도 격차 225점의 상당 부분이 타깃 정의 차이일 수 있다(Cat 쪽은 B3 스택+오프셋으로 763점). **격차를 먼저 좁힌 뒤 상관을 다시 재는 것**이 4번 구간 처방의 실질적 형태.
3. **하지 말 것: 이 상태의 D0을 제출 앙상블에 넣기.** 어떤 w>0도 손해다.

**부산물(다음 실험이 학습부터 다시 하지 않도록)**: fold_2023·2024 × 시드 42/7/2024 × arch D0·C3 예측 벡터, **전 epoch 예측**(다른 fold에서 유도한 배포 epoch을 재학습 없이 읽을 수 있다), 전처리 캐시.
