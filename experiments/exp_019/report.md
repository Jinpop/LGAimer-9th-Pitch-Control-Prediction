# exp_019 — 조건부 편차의 2단 오프셋 (선형/로짓)

**날짜** 2026-08-06 · **대조군** exp_010 D / 진단 출처 exp_018 · **실행** A5000, 실측 **16.67분** (ETA 25~35분, 하회)
**재현 게이트** C0 fold_2024 valid_all Brier @P4 = **0.248261, abs_diff 0.0** — 통과.
추가로 **exp_018 A0 예측 벡터와 max abs diff = 0.0** (seed 42, 253,507행 전체). stage1이 exp_018 A0와 동일 부스터임이 비트 단위로 확인됐다.

> 파일 작성 경위: 실행 에이전트가 하네스 정책상 보고 파일을 직접 쓸 수 없어 본문을 지휘자에게 전달했고, 지휘자가 그대로 저장했다.

## 1. 이 실험이 판정한 것

exp_018 진단의 −1.18e-4는 **기울기를 2024 valid에서 적합한 헤드룸**이었다. 이 실험의 질문은 하나: **선행 시즌에서만 적합한 기울기가 valid 시즌으로 전이되는가.**

**답: 전이된다. 오라클 대비 92.8~94.3% 회수.** 기울기 자체는 27% 미달(0.450 vs 0.616)이지만, Brier 손실이 β에 대해 2차라 최적점 근처가 평탄해서 **미달이 값싸다**. 그리고 미달 방향은 **과소보정** — exp_005 보정C가 죽은 방향(과대보정)의 반대다.

## 2. 대조군 대비 달라진 것 — 전부 열거

**vs exp_018**
1. stage-2 오프셋 추가 (C1/C2/C3). **C0는 exp_018 A0와 스펙 동일** (게이트가 abs_diff 0.0 + 예측 벡터 0.0으로 확인)
2. **플래툰 열이 설계 행렬에 아예 안 들어간다** — exp_018 A1/A2/A3가 넣었던 그 경로를 이 실험이 대체한다
3. stage-1 블록 2개 추가 (2020·2021) — OOF 잔차 공급 전용
4. **fold_2022가 체인 P10 iter로 보고된다** (exp_018은 자기 argmin 오라클). fold_2023·fold_2024의 iter는 exp_018과 동일 — argmin은 곡선의 성질이라 체인을 뒤로 늘려도 안 바뀐다
5. prelim_stats 미재실행 (룩업이 바이트 동일)

**vs exp_010 D** — 위 전부 + **iter 정책 P4 → P10**.

→ C1의 Δ는 **"오프셋 + P10 조합의 효과"**다. 다만 C0가 exp_018 A0와 동일 부스터·동일 iter이므로 C0→C1 Δ는 **오프셋 단독**에 귀속 가능하다 (같은 예측에 오프셋만 더한 것이므로).

## 3. 기울기 적합 방식 (리크 경계)

블록 s := **시즌 < s로 적합한 모델이 시즌 s를 예측**. 블록 2022/2023/2024가 곧 3개 fold이므로 신규 fit은 2020·2021 둘뿐.
valid 시즌 V의 fold는 **s < V 블록만** 풀링. β = Σ(d·r)/Σ(d²), **절편 없음**(절편은 전역 확률 시프트 = exp_005 드리프트 보정, 다른 기전이고 이 base에서 악화했다).

런타임 assert **9개 (seed,fold) 셀 전부 통과**: `max(블록 시즌) < valid 시즌`, `max(룩업 소스 시즌) < valid 시즌`, `설계 행렬에 플래툰·편차·is_* 열 0개`.
`d` 재구성이 `features_platoon.py`가 쓴 값과 **max |diff| = 0.0** (sha 68d63063… 보존, 파일 무수정).

**룩업 미적중 행은 d = 0** — sentinel 채움이 아니라 추정량 자신의 no-op다(셀이 비면 수축식이 무조건부 비율로 정확히 붕괴, 투수 미등장이면 보정 미정의 → p'=p). 21.5%의 행이 여기 해당한다.

**관측**: 2021~2023은 0.505~0.551 (폭 0.046)에 몰려 있고 SE가 ~0.055다 — 서로 구분되지 않는다. **2020만 3분의 1 수준**이며 세 시드에서 똑같이 그렇다. 가중 추세 t = 1.60~1.77 (유의하지 않음)이고, 그 추세는 전적으로 2020 점이 만든다.

**해석(미검증)**: 2020 블록은 체인에서 가장 약한 모델(2019 단일 시즌 211k행, 선행자가 없어 자기 argmin ORACLE iter)이고 룩업 커버리지도 최악(72.1%)이다. β가 낮은 것이 시즌 추세인지 이 블록의 약함인지 **이 실험은 분리하지 못한다.**

→ **exp_005 보정C와 같은 운명은 아니다.** 그건 상수를 시즌 추세로 외삽했다가 과녁을 넘겼다. 여기는 (a) 추세가 유의하지 않고 (b) 풀링 추정이 오라클을 **밑돌아** 과소보정 쪽이다.

## 6. 결론

**C1(선형 × d_s)과 C2(로짓 × d_s)는 사전 등록 기준을 통과했다 — 채택 조건 충족.** C2 ≡ C1 (6자리까지 동일; γ 1.819 ≈ β/p(1−p) = 0.450/0.2498 = 1.802, d의 SD가 0.02로 작고 p가 0.5 근방이라 스케일 형태가 무의미). **더 단순한 C1을 권한다.**

**관측 (사실)**
- 9개 (fold, seed) 셀 전부 음수. 부호 역전 없음.
- |평균Δ|가 C0 시드 std의 **9.5배** — exp_018 A1의 2.42배와 급이 다르다.
- 같은 정보를 트리에 준 exp_018 A1은 −2.7e-05, 오프셋으로 준 C1은 **−1.04e-04 = 3.9배**. 지휘자 진단의 "2.4배" 예상을 상회한다.
- C1 3시드 평균 0.248140 < **exp_016 B3 3시드 평균 0.248208** — 절대값에서 현재 로컬 베스트를 앞선다. 단 **계보가 다르다**(둘 다 exp_010 D 위지만 B3는 모드 스태킹, C1은 오프셋). 결합은 미측정.
- d_s(성공 편차)가 d_r(리버스 편차)보다 명확히 낫다(−10.4e-5 vs −7.0e-5). **exp_018과 반대다** — 거기선 A1(reverse)이 A2(success 추가)보다 나았다. 기전 미설명.

**해석 (가설, 검증 안 됨)**
- 트리가 이 정보를 못 쓴 이유가 "가법 선형 오프셋을 축 정렬 계단으로 근사해서"라는 exp_018 가설과 **부합하지만, 이 실험은 그것을 검증하지 않았다.** 확인된 것은 "오프셋 형태로 주면 3.9배 회수된다"까지다.
- β가 2020에서만 낮은 것이 시즌 추세인지 블록 약함인지 분리 불가 — 미검증.

**±1e-05급 차이를 "노이즈"로 쓰지 않는다.** 시드 3개이고 채점 결정론은 여전히 미실측이다.

## 7. 다음 제안 (지휘자·사용자 판단 대상, 발사하지 않음)

4. **D5 iteration 민감도 재산출** — 코드 결함으로 빠진 값. 수 분이면 되나 stage-1 재실행이 필요하다.
5. **leak-auditor 감사** — config `audit.required: true`. **제출 경로에 넣으려면 필수.** 새 위험 표면은 배포 시 test 2025에 오프셋을 적용하는 경로(≤2024 동결 표 + 선행 시즌 적합 β)가 규칙 2-4를 지키는지.
