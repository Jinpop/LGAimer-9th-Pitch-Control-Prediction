# exp_006 — iter 고정 정책 실험 (ES 불가능한 최종 제출 파이프라인 확정용)

> 2026-08-05 · base: exp_001 (모델·데이터·피처·시드 불변, 변경 변수 = iter 결정 방식만) · 코드 `src/train.py` + `src/eval_fold2022_curve.py` · 수치 전체 `metrics.json`

## 가설
"fold_2023 best_iter를 행수 비율로 스케일(P2)"이 valid를 보지 않는 정책 중 ES 대비 손실 최소다. → **기각** (아래 참조). 대신 파생 정책 P4가 양쪽 시뮬레이션에서 일관되게 최선.

## 셋업
- 동일 시드에서 ES 없이 1000 iter를 1회 학습하면 임의 iter k 모델은 그 prefix와 동일 — fold당 1회 학습으로 전체 iter 곡선 + ES-등가 best_iter(patience 200, logloss) 산출.
- 시뮬레이션 A(본번 모사): train≤2023 모델을 valid 2024로 평가, iter는 **2024를 보지 않고** 결정.
- 시뮬레이션 B(보강): 같은 정책을 1년 앞(train≤2022 → valid 2023)에 적용.
- num_threads=8 (병렬 실험 제약; exp_001은 24). 총 3.82분 + 부록 곡선 평가 23초.
- **P0 재현 검증**: iter=45에서 valid-R Brier 0.249337 — exp_001과 소수 6자리 일치 (8스레드에서도 동일, 스레드 비결정성 미발현. 단 제출은 체크리스트대로 `deterministic: true` 유지).

## 관찰·해석
1. **가설 기각 — P1·P2는 오염된 입력을 승계**: fold_2023의 ES best_iter=5는 F리그 라벨 단절(2023)로 logloss(전체)가 왜곡된 산물. 같은 fold의 **valid-R Brier argmin은 30**으로 정상 대역이다. logloss-ES 값을 승계(P1)하거나 스케일(P2)하면 왜곡이 그대로 전파돼 +0.0013~0.0015 손실.
2. **P4가 일관 최선**: "직전 가용 fold의 valid-R Brier argmin 승계"는 A에서 +0.000106, B에서는 참조 ES보다 오히려 좋음(−0.000901, B의 ES 참조 자체가 왜곡값 5라서). 연도별 오라클 대비 실측 비용: 2023 적용 +0.000078, 2024 적용 +0.000106 — **연 +0.0001 수준**.
3. **argmin은 행수와 무관하게 안정**: R-Brier argmin 수열 48(2022)→30(2023)→45(2024). 학습 행수가 34%→25% 늘어도 증가 추세 없음 → 행수 스케일(P2)의 경험적 근거 없음 (B에서 스케일 64는 무스케일 48보다 오히려 나쁨).
4. **곡선은 30~100 대역에서 평탄**: A에서 iter 30~100 구간 손실 ≤ +0.000115, B에서도 ≤ +0.000376. 위험 구간은 iter<15 (미수렴, −0.001↓)과 iter>200 (과적합, −0.001↓). 고정 100(P3)도 보험으로 나쁘지 않지만 P4보다 일관되게 열위.
5. **라벨 단절 연도에도 R-Brier 곡선은 정상**: 2023 valid조차 R 세그먼트 Brier 기준으로는 argmin 30, iter 48에서 +0.00008 손실뿐 — 2025에 유사한 체제 변화가 와도 40~50대 iter의 하방 위험은 제한적.

## 결론 — **채택: 정책 P4**
**최종 제출(전체 ≤2024 학습) 시 iter 고정 정책 = "마지막 가용 fold(fold_2024)의 valid-R Brier argmin을 스케일 없이 승계" → `num_boost_round = 45` (ES 콜백 제거).**
- fold_2024 R-Brier argmin = 45 (이번 실험 곡선 실측, ES best_iter와 우연히 일치).
- 예상 비용: 도달 불가능한 오라클 대비 ≈ +0.0001 Brier (2개 연도 실측 기반).
- 행수 스케일 금지(근거 없음), logloss-ES 값 직접 승계 금지(F리그 왜곡 전파 위험 — best_iter 산출은 반드시 valid-R Brier 기준).
- 이 결론이 `orchestration/checklists/zip전.md` "iter 고정 정책 config 명기" 항목의 근거 문서다. 제출 config에는 `num_boost_round: 45`, `iter_policy: exp_006 P4` 명기.
