# exp_093 — 4셀 멀티헤드 MLP · stage 0 ρ 프로브

**결론 한 줄**: **ρ′ = 0.9365 ≥ 0.923 → 사전 등록 기각. 축 종료. stage 1 은 돌리지 않았다.**
그리고 그 0.9365 는 **같은 구조 다른 시드끼리의 ρ 대역 [0.9106, 0.9394] 안**이다 —
라벨 분해가 만든 방향 차이가 시드 잡음과 구별되지 않는다.

## 1. 가설과 변경점

현 딥 팔은 99열 → 단일 성공 로짓 · BCE 다. 여기에 AA 라벨 분해 4셀
(`is_mid_only`·`is_rev_only`·`is_both`·`is_wayoff_true`)을 얹어 **5분류 softmax**로 바꿨다
(4실패셀 + 성공, `p_succ = 1 − Σ(4셀)`). 구조가 아니라 **출력층·목적함수** 변경이다.

⚠️ 레지스트리 §8 의 *"logloss → Brier 직접최적화 기각(제23)"* 과 **다른 축이다.**
그쪽은 같은 단일 타깃의 **손실 형태만** 바꿨고, 여기는 **타깃 자체를 5개로 쪼갰다** —
BCE 가 못 보던 *실패의 유형*이 학습 신호로 새로 들어간다.

### 변경 변인 전부 (기준선 = exp_090 `K1632_oot23_s42`)
| # | 바뀐 것 | 크기 |
|---|---|---|
| ① | 출력층 `Linear(64,1)` → `Linear(64,5)` | 파라미터 2,499,265 → 2,499,525 (**+260**) |
| ② | 목적함수 `BCEWithLogitsLoss` → 5분류 소프트 타깃 교차엔트로피 | — |
| ③ | (①이 딸고 온다) **초기화 난수 소비 이동** — `reset_tokenizer` 가 `Sequential` 생성 뒤라 `w`·`b` 토크나이저 초기값이 달라진다 | 피할 수 없다(순서를 바꾸면 재현 게이트가 깨진다) |
| ④ | (②가 딸고 온다) 스텝당 기울기 크기가 달라져 **1632스텝의 유효 학습량**이 함께 바뀐다 | `collapsed5` 대조 raw 점수 **834.76** vs bce **824.28** 이 그 증거 |
| ⑤ | 학습 전용 자산 `qlab.parquet` 투입 | 학습 행에만. 예측면은 NaN |

**고정**: 프레임(`exp089/work/X_oot23.npy`) · 학습 마스크 1,116,277행 · 1632스텝 ·
lr 1e-3 상수 · batch 4096 · D 96 · init ftt · adamw0.01 · drop 0 · 시드 42 · 폭 256/깊이 3.

| 게이트 | 값 |

| 라벨 조립 | 셀 상호배타(합 ≤ 1) · 셀 합 1 인 702,160행이 **전부** y==0 · y==1 행에 셀 0개 → qlab 행 순서가 train.csv 와 같다는 기계 증거 |
| softmax 항등 | `p_succ == 1 − Σ(4셀)` max\|Δ\| **3.33e-16** |

미해결 실패 라벨(`y==0` 인데 셀 0개)은 전체 **329행**, 학습 구간에는 **105행(0.007%)**.
4실패셀에 균등 0.25 를 줬다 — 그래서 **모든 행에서 주변 성공확률 타깃이 정확히 `y`** 이고,
BCE 와 같은 정보를 주면서 실패의 *유형*만 추가된다. 이게 단일 변인을 지키는 규약이다.
`qlab` 자체의 `valid` 열(792행이 0)로 **행을 버리지 않았다** — 버리면 `n_train` 이 달라져 짝짓기가 깨진다.

## 3. ★판정★ ρ′

**ρ′ = corr(멀티헤드 z, 현 딥 팔 z)**, 둘 다 ≤2023 학습(S86) · 둘 다 1시드(S72) ·
둘 다 1632스텝 · 같은 프레임 · 같은 시드 42.

| | 값 |
|---|---|
| **ρ′ (Pearson)** | **0.9365043532585754** |
| ρ′ (Spearman) | 0.9384295881276443 |
| 사전 등록 문턱 | **< 0.923** |
| **판정** | **FAIL — 축 종료** |

### 해석에 필요한 두 바닥 (문턱이 아니라 이번에 잰 값이다)

**ⓐ 같은 구조·같은 타깃·다른 시드** (exp_090 K1632 5시드, 쌍 10개)
평균 **0.92756** · 범위 **[0.91064, 0.93932]**.
→ **ρ′ 0.93650 이 이 대역 안이고 오히려 위쪽이다.** 4셀 분해가 만든 방향 차이는
같은 모델을 다른 시드로 다시 굽는 것보다 **더 작다.**

**ⓑ 출력층 1→5 만의 몫** — `collapsed5` 귀무 대조(실패 4셀에 균등 0.25 → 주변 성공확률 타깃이
BCE 와 동일, 유형 정보만 없음)
`ρ(collapsed5, 현 딥) = 0.95466` · `ρ(collapsed5, 멀티헤드) = 0.94667`.
→ 유형 정보가 ρ 를 **0.9547 → 0.9365 로 0.018 만큼** 내리긴 했다. 방향은 가설대로다.
그러나 **그 폭이 시드 잡음 폭(0.911~0.939, 폭 0.029)보다 작다.**

🔴 **그리고 이 측정은 통과 쪽으로 편향돼 있다.** 1시드끼리의 ρ 는 양쪽의 시드 잡음이 실려
있어, 실제로 배포하듯 5시드 평균끼리 재면 ρ 는 **더 올라간다**(exp_089 stage1 의 다시드 ρ 천장식과 같은 이유).
즉 **하한에서 이미 문턱을 못 넘었다.** 정확한 5시드 사영값을 내려면 멀티헤드 2번째 시드가
필요한데, 사전 등록 기각 조항("학습을 더 하지 마라")대로 **돌리지 않았다.**

## 5. 결론 · 다음 제안

- **기각.** 하드락 G-DIVERSITY 의 재개조건 `ρ′ < 0.923` 을 못 넘었다. 제131 이 제126 곡선을
  역산해 계산한 천장(**G=0 에서도 팔 추가 +0.83**)은 그 조건 아래에서만 성립하므로,
  이 후보는 **천장에도 못 미친다.** 팀 레지스트리 미해결 5건 중 *"4셀 멀티헤드 MLP"* 를 닫는다.
- 🔑 **닫히는 방식이 새롭다.** 지금까지 딥 계열이 닫힌 이유는 *"팔이 안 좋아진다"* 였는데
  (exp_091 22지점, exp_092 19지점), 이번엔 **팔이 좋아지는데도 방향이 안 벌어진다.**
  단독 점수는 +10.8 올랐고 ρ 는 오히려 `z_mate` 쪽으로 붙었다.
- 🔴 **"AA 라벨 분해를 신경망에 주면 새 방향이 생긴다"는 가설이 반증됐다.** 실패 유형은
  트리 팔(AA)이 이미 쓰고 있고, 그 정보를 딥 팔에 더 줘도 **딥 팔을 mate 쪽으로 끌 뿐**이다.
  이건 하드락 **G-NATIVE**(딥 팔 개조 전에 트리 팔이 그 정보를 이미 쓰는지 확인하라)의
  세 번째 실증이다.
- **다음에 이 계열을 다시 열려면** ρ 를 0.92 아래로 내리는 설계가 먼저다. exp_092 가 명시적으로
  ρ 를 벌리려 훑은 19지점이 전부 실패했고, 여기 라벨 축까지 실패했다 —
  **딥 슬롯 안의 다양성 축은 exp_091·092·093 세 실험에서 연속으로 닫혔다.**
- ⚠️ 다만 이 실험이 부산물로 하나를 보여줬다: **`collapsed5`(출력층만 5, 유형 정보 없음)가
  단독 836.93 으로 현행 824.88 보다 +12.05 낫다.** 이건 "다양성" 축이 아니라 **팔 손질** 축이라
  레지스트리 전이계수 ≈0 대역이고(G-EXISTING), 그래서 여기서는 **추천하지 않는다.**
  다만 기전이 유효 학습량이라면 exp_090 의 학습량 축과 같은 것을 다르게 만진 것이므로,
  기록만 남기고 발사 대상으로는 올리지 않는다.
